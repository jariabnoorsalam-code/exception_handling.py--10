# Program to Handle Exceptions Using Try-Except Blocks

## Experiment No: 10

### Objective
To understand and implement exception handling in Python using try-except blocks.

### Description
This Python program demonstrates how to handle runtime errors using try-except blocks. It handles errors such as division by zero and invalid input.

### Requirements
- Python 3.x
- Visual Studio Code / Python IDLE

### Source Code
The main Python program is available in the file:

`exception_handling.py`

### How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python exception_handling.py
```

### Expected Output

**Normal Input:**
```text
Enter the first number: 20
Enter the second number: 5
Result: 4.0
Program execution completed.
```

**Division by Zero:**
```text
Enter the first number: 20
Enter the second number: 0
Error: Cannot divide by zero!
Program execution completed.
```

### Conclusion
This experiment demonstrates how Python exception handling works. It helps prevent unexpected program termination and makes programs more reliable.
